## Phase Goal

**As an** authorized HR user, **I want to** download the currently displayed T-13 grid as Excel or CSV, **so that** I can submit the statutory timesheet to payroll without retyping it.

<objective>
Export vertical slice (EXP-01, EXP-02, EXP-03). Add two new Flask GET routes that reuse the existing `/timesheet` route's role-scope resolution and ORM data-loading, generate a T-13-formatted `.xlsx` (openpyxl, merged headers, Cyrillic labels — D-03) and a UTF-8-BOM semicolon `.csv` (D-05), and stream them as file downloads with the `T13_<dept>_<YYYY-MM>` filename pattern (D-04). Add "Скачать XLSX" / "Скачать CSV" buttons to the timesheet selector bar (D-01, D-02).

This is a complete end-to-end slice: after this plan, a real user who could only view the grid can now download it. It turns tests 1-3 of 04-01 from xfail to pass.
