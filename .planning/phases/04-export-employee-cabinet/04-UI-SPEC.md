## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, `padding: 4px` in table cells (`.sym-cell`, `thead th`) |
| sm | 8px | Input padding (`padding: 8px 12px`), button padding (`padding: 8px 16px`), form-group row gap |
| md | 16px | Page horizontal padding (`padding: 16px 24px` in header), selector-bar padding, form-group column gap |
| lg | 24px | Page content padding (`padding: 24px 20px`), card padding (`padding: 24px`) |
| xl | 32px | Card padding (large cards: `padding: 32px`), stat-card bottom margin |
| 2xl | 48px | Not in use — reserved |
| 3xl | 64px | Not in use — reserved |

Exceptions:
- Touch target minimum 44px height for export buttons (accessibility — download action must be easy to hit on any screen)
- Stats card value font-size 26px (display size, not a spacing exception)
- Header logo icon: 34px × 34px (fixed dimension, existing pattern)

Components to be used in this phase (all vanilla CSS, existing patterns):

### Export Buttons (new addition to `/timesheet` selector bar)

```
.btn-secondary {
  padding: 8px 16px;
  background: #fff;
  border: 1px solid #cfd8dc;
  border-radius: 8px;
  font-size: 13px;
  font-weight: 600;
  cursor: pointer;
  color: #546e7a;
  text-decoration: none;
  display: inline-flex;
  align-items: center;
  gap: 6px;
  height: 36px;
}
.btn-secondary:hover { background: #f4f6fb; }
```

Placement: added to the right end of the existing `.selector-bar` in `timesheet.html`, after the "Показать табель" primary button. Two buttons: "Скачать XLSX" and "Скачать CSV". Both rendered as `<a href="...">` anchor tags (GET download links), not `<button>` elements — they navigate to the export route with the current query params.

Visual distinction from `.btn-primary`: white background with border vs. blue filled. This matches the established `.btn-secondary` pattern from `superadmin.html` and `dept_admin.html`.

### Stats Cards (employee cabinet — `employee.html`)

Reuse the `.stats-grid` + `.stat-card` pattern from `dept_admin.html`:

```
.stats-grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 12px; margin-bottom: 20px; }
.stat-card  { background: #fff; border: 1px solid #e2e6f0; border-radius: 12px; padding: 16px; }
.stat-label { font-size: 11px; color: #78909c; margin-bottom: 6px; text-transform: uppercase; letter-spacing: 0.05em; }
.stat-val   { font-size: 26px; font-weight: 600; }
```

Three cards (left to right): Опоздания (orange `#E65100`), Отсутствия (orange `#E65100`), Ранний уход (orange `#E65100`). All counts are integers — no decimals.

Responsive: `grid-template-columns: 1fr 1fr` at `max-width: 600px` (existing mobile breakpoint pattern).

### Month Selector (employee cabinet)

Reuse `.selector-bar` + `.form-group` pattern from `timesheet.html`. Single `<input type="month">` with `min` and `max` attributes set server-side to restrict to previous month and current month only. Label: "Месяц". Submit button: "Показать" (`.btn-primary`).

### T-13 Grid (employee cabinet — read-only single row)

Reuse `.table-card` + `<table>` structure from `timesheet.html`. Differences from admin grid:
- No `.editable` class on any cell — `onclick` and `tabindex` attributes omitted
- No dept selector (employee sees only their own row)
- `title` attribute on each `<td>` cell with arrival/departure times: `"Приход: HH:MM / Уход: HH:MM"` or `"Приход: HH:MM / Уход: —"` when no check-out
- One data row + one totals row; no multi-employee summing

### Page Layout (`employee.html`)

Same structure as `timesheet.html`:
- `<header>` with logo, user badge, "← Мой кабинет" back-link (not applicable — this IS the cabinet), and "Выйти" link
- Header title: `МедКонтроль — Личный кабинет` (matches `dashboard.html`)
- `.page` wrapper: `max-width: 1400px; margin: 0 auto; padding: 24px 20px`
- Section order top-to-bottom:
  1. `<h1 class="page-title">` — "Мой табель"
  2. Stats grid (3 cards)
  3. Month selector bar (`.selector-bar`)
  4. T-13 grid (`.table-card`)

### Error Toast

Reuse `#error-toast` pattern from `timesheet.html` for any load or access errors. Hidden by default, shown via `showToast(msg)`. No new toast component needed.

## Interaction Contract

### Export Buttons on `/timesheet`

- Both buttons are `<a>` anchor tags with `href` built from current `dept_id` and `month` query params
- `href` format: `/timesheet/export/xlsx?dept_id={{ dept_id }}&month={{ month_str }}`
- No JavaScript required — pure server-side GET download
- Buttons are only rendered when `dept_id` is set (same guard as the grid)
- If `dept_id` is absent, buttons are hidden (not disabled) — same behavior as the empty-state message
- Role scope enforced server-side; buttons are visible to all authorized roles (dept_admin, org_admin, superadmin)

### Employee Cabinet Month Selector

- `<form method="GET" action="/employee">` — same server-render pattern as timesheet
- `<input type="month">` with `min="{{ prev_month }}"` and `max="{{ current_month }}"` set from server template context
- Defaults to current month on first load
- No AJAX — full page reload on submit

### T-13 Grid (employee cabinet — read-only)

- No `onclick` handlers — no override dropdown rendered
- Native `title` attribute on each `<td class="sym-cell">` carries the tooltip text
- Cell styling: same `.sym-bg` and `.sym-fg` color maps as `timesheet.html`
- Totals row at bottom: same `.totals-row` class, one employee's totals only

### Keyboard Accessibility

- Export anchor buttons are natively focusable (`<a>` elements)
- Month input and submit button are natively keyboard-accessible
- T-13 grid cells have no `tabindex` in read-only mode (no keyboard override interaction needed)
- Error toast visible for 3000ms then auto-hides (matches existing `showToast` pattern)

## Implementation Notes for Executor

These notes supplement the design contract with implementation-specific guidance for this codebase:

1. **Export anchor href construction (Jinja2):**
   ```html
   {% if dept_id %}
   <a href="/timesheet/export/xlsx?dept_id={{ dept_id }}&amp;month={{ month_str }}" class="btn-secondary">Скачать XLSX</a>
   <a href="/timesheet/export/csv?dept_id={{ dept_id }}&amp;month={{ month_str }}" class="btn-secondary">Скачать CSV</a>
   {% endif %}
   ```

2. **Stats card semantic colors in employee cabinet:** All three stats (late, absent, early) use `.stat-val.orange` (`#E65100`) — these are negative indicators, not neutral counts.

3. **Tooltip on cells with no check-in (future days or В/НН):** Use `title="Нет данных"` — do not show `"Приход: — / Уход: —"` as that implies data was expected.

4. **T-13 xlsx header structure (openpyxl — Claude's discretion area):**
   - Row 1 (merged across all columns): "ТАБЕЛЬ УЧЁТА РАБОЧЕГО ВРЕМЕНИ (Форма Т-13)"
   - Row 2 (merged): org name + " — " + dept name + " — " + month/year in Russian (e.g., "МедКонтроль — ВОП-1 — Июнь 2026")
   - Row 3: column headers (Сотрудник, day numbers 1–31, Я, Ч, П/НН, О, Б/К)
   - Rows 4+: employee data rows
   - Last row: totals (Итого)

5. **No changes to existing `timesheet.html` CSS** — only add the two export anchor elements and the `.btn-secondary` class definition (if not already present; check before adding).

6. **`employee.html` inherits the exact `<header>` structure from `dashboard.html`** — logo, user badge, "Выйти" link. No back-to-admin link for employees (they have no admin panel to return to).
