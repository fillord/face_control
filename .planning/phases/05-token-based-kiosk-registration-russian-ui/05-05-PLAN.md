Add the org_admin dashboard UI to drive these actions and display the live kiosk and registration URLs.

Purpose: Org admins must self-manage their kiosk/registration access without editing JSON or running migrate.py. This closes the CONTEXT "Specific Ideas": change PINs, regenerate reg_token to invalidate old links, and time-limit registration campaigns.
Output: Upgraded PATCH /api/orgs/<org_id>/settings, an org_admin settings panel, and settings tests.
</objective>
