<objective>
Overhaul the kiosk check-in UX and add three RBAC/audit features to the Flask + SQLAlchemy attendance system:

1. Replace spacebar/continuous auto-scan with two explicit buttons «Прибыл» (check-in) and «Убыл» (check-out). The clicked button determines the attendance event — no more implicit state machine guessing.
2. Let `org_admin` (and `superadmin`) manually correct an employee's check-in/check-out timestamps for a date. `dept_admin` must NOT be able to.
3. Add a read-only `hr_viewer` role scoped to one organization (reports / timesheet / summary view; no mutations).
4. Add a super-admin-only audit log recording every sensitive action with timestamp, acting user, action type, target, and old→new values.

Purpose: Make kiosk attendance unambiguous and add accountability + a limited HR read role without a DB migration beyond an additive table.
Output: New AuditLog model + audit page, mode-aware recognition, manual-edit endpoint, hr_viewer wired through RBAC, and write_audit() instrumentation on sensitive routes.
</objective>
