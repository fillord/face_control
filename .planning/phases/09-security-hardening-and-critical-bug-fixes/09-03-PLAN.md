<objective>
Add CSRF protection (Flask-WTF / `CSRFProtect`) to the HTML form POST routes — `/login` and `/profile` — while leaving every JSON `/api/*` route (including the kiosk and all fetch-based admin calls) exempt, per D SEC-03.

Purpose: Prevent cross-site request forgery on the two browser-form credential routes without breaking the ~40 JSON API endpoints that the SPA-style admin pages call via `fetch`.
Output: `flask-wtf` installed and pinned; `CSRFProtect` initialized on `app`; JSON routes exempt; `{{ csrf_token() }}` hidden inputs added to the real HTML forms (login.html, profile.html).
</objective>
