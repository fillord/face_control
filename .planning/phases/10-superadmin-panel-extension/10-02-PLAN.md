| browser to DELETE /api/kiosk/<org_token>/devices/<id> | authenticated destructive revoke |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-05 | Information Disclosure | devices/logs endpoints | mitigate | require_role("superadmin") returns 403 for all other roles; verified by tests |
| T-10-06 | Repudiation | device revoke | mitigate | write_audit("device_revoke") records actor, target, old_value before return |
| T-10-07 | Elevation | revoke URL org_token from client | accept | DELETE endpoint already enforces org scope for org_admin; superadmin bypass is by design; org_token only identifies the target device |
| T-10-08 | Tampering | log/device text rendering | mitigate | escapeHtml applied to all DB-sourced strings before innerHTML |
| T-10-09 | Denial of Service | logs query size | mitigate | LogEntry query capped at limit 500 (no unbounded scan) |
</threat_model>
