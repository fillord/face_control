## Interaction Contract

### Grid Navigation

- Month/dept selector: `<form method="GET">` — full page reload on submit. No AJAX for grid render. URL becomes bookmarkable: `/timesheet?dept_id=X&month=YYYY-MM`.
- Default month: current calendar month (server-computed `datetime.now().strftime('%Y-%m')`).
- dept_admin: no dept selector visible; dept fixed from `session['dept_id']`.
- org_admin: single `<select>` of depts in their org.
- superadmin: single `<select>` with `<optgroup>` per org.

### Cell Editing (dept_admin and above)

- Cells that are editable: any work-day cell (not В) for an employee in scope.
- Click on editable cell: open inline override dropdown (positioned below the clicked cell using JS `getBoundingClientRect()`).
- Select a symbol from dropdown: POST to `/api/timesheet/override` with `{emp_id, date, symbol}`; on success, update cell in-place without page reload (JS updates cell background + text from response).
- Select "Восстановить авто": DELETE to `/api/timesheet/override` with `{emp_id, date}`; cell reverts to auto-derived symbol.
- Viewer role: cells are not clickable; no dropdown; `cursor: default`.

### Override API Response (client-side update)

On success (200): JS receives `{symbol: "Б", auto: false}` and updates cell HTML and color class in place. No full page reload.
On error (403/422): dropdown closes; inline error toast appears at top of `.page` for 3 seconds — `background: #FFEBEE; border: 1px solid #EF9A9A; border-radius: 8px; padding: 10px 16px; font-size: 13px; color: #C62828`.

### Holiday-Missing Banner

Rendered server-side (Jinja2 `{% if missing_holiday_year %}`). Static — no JS interaction. Always visible for that year until holiday data is added to code.

## Accessibility Constraints

- All `<th>` elements must carry `scope="col"` (or `scope="row"` for employee name column) for screen reader compatibility with a dense data grid.
- Symbol-only cells must include `title` attribute with full Russian name: e.g. `title="Я — явка"`, `title="НН — неявка по невыясненной причине"`.
- Inline dropdown must be keyboard-reachable: `tabindex="0"` on the cell; dropdown opens on `Enter`/`Space`; `Escape` closes it.
- Color is not the sole differentiator: symbol letter is always present in cell text.
- Focus ring: `outline: 2px solid #1565C0` on focused interactive cells (not suppressed with `outline: none`).
