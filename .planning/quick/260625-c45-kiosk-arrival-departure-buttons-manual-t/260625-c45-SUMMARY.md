## What Was Built

### Task 1 — AuditLog Model + write_audit()
- Added `AuditLog` model (table `audit_log`) to models.py with id, ts, actor_user_id, actor_username, action, target_type, target_id, old_value, new_value columns
- Added `write_audit()` helper in app.py: reads session user, serializes dict values as JSON, enforces 50000-row cap, wraps commit in try/except with rollback and silent print on failure
- Instrumented: create/update/delete user (user_create/update/delete), create/update/delete org (org_create/update/delete), create/update/delete dept (dept_create/update/delete), add_employee and register_token_submit (employee_register)
- For update routes: old values captured BEFORE mutation so audit is accurate

### Task 2 — Mode-Aware Recognize + Kiosk Buttons
- `/api/recognize` now accepts optional `mode` field: "arrive" records check_in only (never overwrites existing arrival — returns `already_in` event), "depart" records check_out only (returns 409 `no_checkin` if no arrival), absent/invalid falls back to legacy state machine
- kiosk.html: removed spacebar listener and setInterval auto-scan; added «Прибыл» and «Убыл» action buttons shown when DEVICE_AUTHORIZED && hasEmployees
- Added `currentMode` JS variable; `startMode(mode)` sets mode, hides buttons, calls recognize(); `resetToIdle()` restores button screen after COOLDOWN_MS
- New events handled in error branches and showResult: `already_in` shows info badge, `no_checkin` shows error with explanation

### Task 3 — hr_viewer Role
- Added `hr_viewer` to ROLE_HIERARCHY between dept_admin and viewer
- Added to ALLOWED_LOGIN_ROLES and ROLE_DISPLAY ("HR-наблюдатель")
- Login routes: hr_viewer redirected to /timesheet
- Read access granted on: /timesheet, /timesheet/export/xlsx, /timesheet/export/csv, /api/attendance, /api/attendance/dates, /api/stats, /api/dept_attendance_today, /api/employees, /api/depts, /org_admin/partial/reports, /org_admin/partial/timesheet
- All scope branches treat hr_viewer same as org_admin (filtered to session org_id)
- can_edit remains False for hr_viewer everywhere
- No mutating routes include hr_viewer

### Task 4 — Manual Attendance Time Edit
- Added `POST /api/attendance/manual` with `@require_role("superadmin", "org_admin")` — dept_admin/hr_viewer → 403
- Validates date (strptime), validates times against regex + range check, normalizes HH:MM → HH:MM:SS
- Org scope gate: org_admin restricted to own org
- Upserts AttendanceRecord; event_type set to "manual"
- Writes `manual_time_edit` AuditLog row after commit with old/new check_in/check_out values
- org_admin.html: added «Время» button per employee row, manualTimePanel form with date + check_in + check_out inputs, success/error display via inline message element

### Task 5 — Superadmin Audit Log Viewer
- Added `GET /audit` → renders audit.html (superadmin only)
- Added `GET /api/audit` → returns last 500 AuditLog rows as JSON with optional ?action= and ?actor= substring filters
- Created templates/audit.html: table with Время/Пользователь/Действие/Объект/Было/Стало columns; color-coded action badges; JSON pretty-print for old/new values; filter controls
- Added «Аудит» nav tab to templates/superadmin.html
