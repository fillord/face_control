Then `overrides.setdefault(emp_id, {})[date_str] = symbol; save_timesheet_overrides(overrides)`; return `jsonify({"symbol": symbol, "auto": False})`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/timesheet/override (POST/DELETE) | emp_id, date, symbol are attacker-controlled JSON; scope and symbol must be validated server-side |
| override handler → timesheet_overrides.json | concurrent HR cell clicks can race on the JSON write |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-privesc | Elevation of privilege | override emp_id scope | mitigate | Server reads emp.dept_id/emp.org_id from employees.json and compares to session; dept_admin/org_admin out-of-scope → 403 (D-05) |
| T-03-inject | Tampering | override symbol value | mitigate | Whitelist MANUAL_SYMBOLS = {Б,К,П}; any other value → 422; auto symbols never accepted (Pitfall 7) |
| T-03-delete-auth | Elevation of privilege | DELETE override route | mitigate | POST and DELETE share one `@require_role("dept_admin","org_admin","superadmin")` decorator |
| T-03-race | Tampering | timesheet_overrides.json write | mitigate | save_timesheet_overrides uses fcntl.flock(LOCK_EX) + atomic os.replace (save_users pattern) |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | stdlib only — no installs (RESEARCH Package Legitimacy Audit) |
</threat_model>
