<objective>
First vertical slice of Phase 2: the data foundation and the one-time migration. After this plan, an operator can run `python migrate.py` and the live system's single employee (and any others) is fully assigned to a default org/dept with a work schedule — and the face recognizer still trains and recognizes. This is the end-to-end capability that every later slice (CRUD, dashboards, kiosk) depends on, because no org/dept data exists until migration runs.

Purpose: Deliver MIG-01 and MIG-02 (strictly additive migration + label integrity check) and the load/save helpers that all later API routes consume.
Output: Extended `app.py` (new file constants + four load/save helpers), new standalone `migrate.py`.
</objective>
