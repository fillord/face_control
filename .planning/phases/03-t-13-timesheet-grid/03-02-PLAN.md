<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /timesheet (GET) | dept_id and month query params are attacker-controlled; scope must be enforced server-side |
| /timesheet → attendance.json / employees.json | read-only data access; no client value trusted for symbol computation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-scope | Spoofing | `?dept_id=X` on /timesheet | mitigate | dept_admin dept_id forced from session (param ignored); org_admin dept must match session org_id else 403; superadmin unrestricted (D-08) |
| T-03-privesc-read | Elevation of privilege | employee filter in timesheet() | mitigate | Filter employees by resolved dept_id read server-side from employees.json; None dept_id treated as out-of-scope (Pitfall 3) |
| T-03-clientcompute | Tampering | symbol values | mitigate | Symbols computed server-side at render time from attendance.json; never read from client |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | stdlib only — no installs (RESEARCH Package Legitimacy Audit) |
</threat_model>
