<objective>
Add a public, token-gated, mobile-friendly employee self-registration flow at /register/<reg_token> with server-side expiry enforcement and bcrypt reg_pin verification, while keeping the existing authenticated admin /register page intact. Also enforce the Phase 5 login role restriction (only superadmin/org_admin/dept_admin may log in).

Purpose: Employees register themselves from their phones via a shared expiring link, without an account and without a keyboard popup. The org is identified by reg_token, never by URL-exposed UUID. Login must reject any legacy/disallowed role.
Output: /register/<reg_token> page route + verify_pin/submit API + register_token.html + login allowlist + tests.
</objective>
