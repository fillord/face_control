<objective>
Allow org_admin to edit employee profile (name, position, department) and work schedule inline from the Employees tab.

Purpose: Currently the Employees tab only allows dept reassignment via dropdown. Org_admins need to edit name, position/role, and work schedule without navigating away. The edit form opens inline (no page navigation); saves trigger two PATCH calls — one to /api/employees/<emp_id> for profile fields, one to /api/employees/<emp_id>/schedule for schedule fields — then reload the employee list.

Backend change: Expand the PATCH /api/employees/<emp_id> allowed_keys whitelist to include 'name' and 'role' (used as position field in the Employee model). Org_admin scope gate: emp.org_id must match session["org_id"].

Output: Expanded PATCH route in app.py + inline edit form in org_admin.html.
</objective>

       function startEditEmp(empId) {
         const emp = allEmployees.find(e => e.id === empId);
         if (!emp) return;
         document.getElementById('editEmpId').value = empId;
         document.getElementById('editEmpName').value = emp.name || '';
         document.getElementById('editEmpPosition').value = emp.role || '';
         // Populate dept select
         const deptSel = document.getElementById('editEmpDept');
         deptSel.innerHTML = allDepts.map(d =>
           `<option value="${d.id}" ${d.id === emp.dept_id ? 'selected' : ''}>${escapeHtml(d.name)}</option>`

         // Populate schedule
         const sched = emp.schedule || {};
         document.getElementById('editEmpStart').value = sched.start || '09:00';
         document.getElementById('editEmpEnd').value = sched.end || '18:00';
         const workDays = sched.work_days || [1,2,3,4,5];
         document.getElementById('editEmpDays').querySelectorAll('input[type=checkbox]').forEach(cb => {
           cb.checked = workDays.includes(parseInt(cb.value));

       async function saveEmployeeEdit() {
         const empId = document.getElementById('editEmpId').value;
         const name = document.getElementById('editEmpName').value.trim();
         const role = document.getElementById('editEmpPosition').value.trim();
         const dept_id = document.getElementById('editEmpDept').value;
         const start = document.getElementById('editEmpStart').value;
         const end = document.getElementById('editEmpEnd').value;
         const work_days = Array.from(
           document.getElementById('editEmpDays').querySelectorAll('input[type=checkbox]:checked')
         ).map(cb => parseInt(cb.value));
         const errEl = document.getElementById('editEmpError');
         errEl.classList.add('hidden');

         if (!name) {
           errEl.textContent = 'ФИО обязательно.';
           errEl.classList.remove('hidden');
           return;
         }
         if (work_days.length === 0) {
           errEl.textContent = 'Выберите хотя бы один рабочий день.';
           errEl.classList.remove('hidden');
           return;
         }

         try {
           // Patch profile
           const profileResp = await fetch(`/api/employees/${empId}`, {
             method: 'PATCH',
             headers: {'Content-Type': 'application/json'},
             body: JSON.stringify({name, role, dept_id}),
           });
           if (!profileResp.ok) {
             const d = await profileResp.json();
             errEl.textContent = d.error || 'Ошибка при сохранении.';
             errEl.classList.remove('hidden');
             return;
           }
           // Patch schedule
           const schedResp = await fetch(`/api/employees/${empId}/schedule`, {
             method: 'PATCH',
             headers: {'Content-Type': 'application/json'},
             body: JSON.stringify({start, end, work_days}),
           });
           if (!schedResp.ok) {
             const d = await schedResp.json();
             errEl.textContent = d.error || 'Ошибка при сохранении графика.';
             errEl.classList.remove('hidden');
             return;
           }
           cancelEmployeeEdit();
           await loadEmployees();
           await loadDepts();
         } catch (e) {
           errEl.textContent = 'Ошибка соединения.';
           errEl.classList.remove('hidden');
         }
       }

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| org_admin browser → PATCH /api/employees/<id> | Attacker could send arbitrary emp_id; scope gate checks emp.org_id == session org_id |
| name/role fields | User-supplied strings written to DB; name is stripped; role is stored as-is (position string, not RBAC role) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-03-A | Elevation of Privilege | PATCH /api/employees/<emp_id> | mitigate | org_admin scope gate: emp.org_id != caller_org_id → 403; superadmin unrestricted |
| T-07-03-B | Tampering | Employee.role column via PATCH | accept | Employee.role stores job position string (e.g. "Врач"), not RBAC role; RBAC role is User.role, separate table |
| T-07-03-C | XSS | employee name rendered via escapeHtml() | accept | All name fields go through escapeHtml() before DOM insertion |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan |
</threat_model>
