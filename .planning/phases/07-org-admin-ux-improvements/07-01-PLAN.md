<objective>
Fix the race condition bug where the department employee counter always shows 0.

Purpose: The root cause is that init() calls Promise.all([loadDepts(), loadEmployees()]) in parallel — loadDepts() calls renderDepts() immediately after its fetch resolves, but allEmployees may still be [] at that point because loadEmployees() has not finished yet. The fix changes init() to be sequential: await loadEmployees() first, then await loadDepts() so allEmployees is populated before renderDepts() reads it. Also fix reassignEmployee() to reload both datasets so the count stays accurate after reassignment.

Output: templates/org_admin.html with corrected init() and reassignEmployee() logic.
</objective>
