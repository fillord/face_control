<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/dept_attendance_today, /api/superadmin_stats | scoped reads; a leak would expose other depts' attendance |
| browser → schedule PATCH | untrusted time/work_days input crosses into stored employee record |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-I2 | Information Disclosure | dept_admin reading other depts' attendance | mitigate | dept_attendance_today filters employees by session dept_id for dept_admin (Pitfall 3) |
| T-02-T7 | Tampering | malformed schedule (e.g. "25:00", non-list work_days) corrupting render | mitigate | server validates HH:MM range + work_days ints 1-7, 400 on failure (Security V5) |
| T-02-E2 | Elevation | dept_admin editing schedule of an employee outside their dept | mitigate | schedule PATCH 403 unless target employee dept_id == session dept_id |
| T-02-T8 | Tampering | schedule PATCH used to overwrite label/name | mitigate | route whitelists start/end/work_days only |
| T-02-SC | Tampering | npm/pip installs | accept | No new packages this phase; legitimacy gate N/A |
</threat_model>
