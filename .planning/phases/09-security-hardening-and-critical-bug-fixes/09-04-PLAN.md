## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-09 | Elevation of Privilege | non-superadmin altering recognition threshold | mitigate | @require_role("superadmin") + 50-120 server-side validation |
| T-09-10 | Information Disclosure | DB backup exposes all data | mitigate | @require_role("superadmin") on /api/backup/db; SECURE/HttpOnly session (SEC-04) protects the session needed to reach it |
| T-09-11 | Tampering | invalid threshold value breaking recognition | mitigate | integer + [50,120] range check; recognize() falls back to 80 on non-numeric value |
</threat_model>
