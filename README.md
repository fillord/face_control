# МедКонтроль — Система учёта рабочего времени по лицу

Система распознавания лиц для учёта посещаемости сотрудников поликлиники.

## Требования

- Python 3.8+
- Веб-камера
- Браузер с поддержкой WebRTC (Chrome, Firefox, Edge)

## Установка

```bash
cd clinic_app

# Установить зависимости
pip install flask opencv-contrib-python numpy

# Запустить сервер
python app.py
```

## Страницы

| URL | Описание |
|-----|----------|
| `http://localhost:5050/` | **Киоск** — ставится у входа, автоматически распознаёт лица |
| `http://localhost:5050/register` | **Регистрация** — страница для добавления сотрудников и съёмки лица |
| `http://localhost:5050/admin` | **Отчёты** — журнал посещаемости с экспортом в CSV |

## Как использовать

### 1. Регистрация нового сотрудника
1. Откройте `/register`
2. Введите ФИО и должность → «Добавить сотрудника»
3. Выберите сотрудника из списка
4. Попросите сотрудника встать перед камерой
5. Сделайте **5–10 снимков**: прямо, чуть левее, правее, разное освещение
6. Сотрудник готов к работе ✓

### 2. Работа киоска
- Откройте `/` на компьютере у входа на полный экран
- Камера каждые 1.5 секунды автоматически проверяет кадр
- Если сотрудник распознан — фиксирует приход или уход
- Показывает ФИО, должность, время, и сколько отработано

### 3. Отчёты
- Откройте `/admin`
- Выберите дату
- Скачайте CSV при необходимости

## Алгоритм распознавания

Используется **dlib / face_recognition (128-мерные эмбеддинги лиц)**:
- Не требует GPU или интернета
- Работает в реальном времени

## Хранилище данных

Данные хранятся в **SQLite** (`data/app.db`) плюс два вспомогательных
файла/каталога:

```
data/
  app.db              — основная база (сотрудники, посещаемость, пользователи, организации)
  encodings.json      — 128-мерные эмбеддинги лиц для распознавания
  faces/
    {emp_id}/
      face_1.jpg       — образцы лиц для обучения
      face_2.jpg
      ...
```
