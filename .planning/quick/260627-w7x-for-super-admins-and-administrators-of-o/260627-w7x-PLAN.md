<objective>
Bring the superadmin Users tab to full CRUD parity with the org-admin Users tab. The
description asks for password reset and a CRUD system (delete, change) for super admins
and organization administrators.

Investigation finding (drives scope): the Flask backend already exposes complete user
CRUD — `PATCH /api/users/<id>` accepts `{password}` and `{active}`, and
`DELETE /api/users/<id>` removes a user, both authorized for `superadmin`. The org-admin
template (`org_admin.html`) ALREADY has the full UI (create, edit + password reset,
toggle active, delete). The ONLY gap is `superadmin.html`, whose Users tab currently
exposes just "create" and "toggle active" — no password reset and no delete.

This plan is frontend-only: add an edit-password panel, a password-reset save handler,
and a delete button + handler to the superadmin Users tab, reusing the existing backend
routes. No backend changes are required.

Purpose: superadmin gains password-reset and delete capability the request calls for.
Output: updated `templates/superadmin.html`.
</objective>
