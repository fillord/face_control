<objective>
Replace the identity-based kiosk URL scheme with token-based routing, upgrade kiosk PIN verification to bcrypt, rebuild the kiosk PIN entry as a touchscreen button pad, and surface the department name on recognition. Add a reusable Russian error page for bad tokens.

Output: New /kiosk/<org_token> + /api/kiosk/<org_token>/verify_pin routes, rebuilt kiosk.html PIN pad, error_token.html, and kiosk route tests.
</objective>
