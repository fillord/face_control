<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| JSON files → app.db (migration) | One-shot bulk transform; a shape error here permanently corrupts the new store |
| kiosk face → AttendanceRecord write | Public unauthenticated route writes attendance; must not double-record or lose check-outs |
| operator → migrate_to_sqlite.py | Re-running the script must be safe (idempotent), never duplicating or dropping rows |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-11 | Tampering | label preservation through migration | mitigate | migration copies `int(emp["label"])` verbatim (D-14); test_sqlite_migration asserts the label value; human checkpoint spot-checks app.db labels vs JSON |
| T-06-12 | Repudiation | idempotent re-run | mitigate | all inserts use on_conflict_do_nothing / query-then-skip; second run produces zero new rows (DB-02), verified by test + checkpoint step 3 |
| T-06-13 | Information Disclosure | app.db file permissions | mitigate | .gitignore prevents committing app.db; operator runs migration in data/ which inherits the existing dir perms (match data/*.json, chmod 600 for users) — noted in checkpoint |
| T-06-14 | Tampering | attendance double-write at kiosk | mitigate | check-in/out logic uses filter_by(emp_id,date).first() then sets check_out only when None (preserves original state machine); event_type records the transition; commit once per recognition |
| T-06-15 | Denial of Service | migration on missing timesheet_overrides.json | accept | _load_json returns {} for absent files (Pitfall 7); migration proceeds without that table's data |
</threat_model>
